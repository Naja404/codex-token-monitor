# v1.4.9 · 自适应弹窗 / Adaptive Popover

## 中文

- macOS 概览弹窗根据实际内容调整高度，少量供应商不再占据固定 540 点的视口。
- 高度上限为打开弹窗所在屏幕可用高度的一半，排除菜单栏和 Dock。超过上限时，额度卡片区域滚动，标题、刷新、设置和退出按钮保持可见。
- 展开、折叠、供应商开关及数据变化后重新测量；没有启用供应商时的引导页也受相同上限约束。
- 原生控制器及 Touch Bar 保持复用；不改变额度读取、通知或回写规则。Windows 仅同步版本号。
- 玻璃卡片采用均匀的单层描边，去掉渐变边框和内圈高光，减轻上下边缘看起来内凹的倒角感，保留玻璃底色与圆角。
- 本地构建版本 **1.4.9 (21)**，提供 Developer ID 签名的 App、拖拽到 Applications 的 DMG 及兼容 ZIP。公证及校验结果随本地构建记录提供；本说明不代表 GitHub 已发布此版本。

168 项 Swift 回归通过，包括真实 NSPopover 的单供应商收缩、多供应商增高、展开折叠恢复、500 / 300 点上限、原生内容滚动及浅深色主题。README 预览使用隔离测试数据。

退出旧版后挂载 DMG，将 App 拖入 Applications 并选择替换，再打开“关于与更新”确认版本。

## English

- The macOS quota popover fits its content instead of keeping a fixed 540-point viewport.
- Its height is capped at half the available height of the screen where it opens, excluding the menu bar and Dock. Only the quota cards scroll beyond that cap; the header and footer actions remain visible.
- Expanding or collapsing details, toggling providers and changing data remeasure the content. The empty-provider guide follows the same cap.
- The native controller and Touch Bar are reused. Quota reads, notifications and write-back behavior stay unchanged. Windows receives a version bump only.
- Glass cards use one uniform outline instead of a variable-brightness border and an inset highlight, reducing the indented bevel appearance while preserving the glass fill and rounded corners.
- Local build **1.4.9 (21)** includes a Developer ID signed app, a drag-to-Applications DMG and a ZIP. Notarization and integrity results accompany the local build; these notes do not imply a published GitHub release.

All 168 Swift regression tests passed, including real NSPopover resizing, collapse recovery, 500/300-point caps, native scrolling and light/dark themes. README previews use isolated test data.

Quit the old app, mount the DMG, drag the app into Applications and replace the previous copy. Confirm the version in About & Updates.
