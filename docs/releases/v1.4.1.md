# v1.4.1 · 菜单栏翻牌 / Menu-bar Split-Flap

## 中文

### macOS 更新

- 自动轮播额度组时新增机场信息牌式翻牌：约 0.32 秒上下半片翻转，两行略微错开。
- 保留系统菜单栏单色和透明背景，不增加背景色块。普通额度刷新、手动切换不播放翻牌。
- 轮播期间保留已显示内容所需的最大宽度，动画中不改变宽度；点击菜单栏立即结束动画，再按原有逻辑定位弹窗。关闭轮播并收起弹窗后恢复紧凑宽度。
- 支持“供应商设置 → 外观 → 关闭动效”和 macOS“减少动态效果”；动画结束后停止绘制定时器，不增加接口请求。
- 菜单栏无障碍标签提供当前供应商和完整额度文本。README 更新翻牌 GIF、使用说明及下载链接。
- 保留 v1.4.0 多供应商、三套主题、Touch Bar 小猫及睡眠 Zzz 漂浮效果；本次不改动额度接口和刷新频率。

### 安装与验证

- **macOS arm64 ZIP**：Apple Silicon，macOS 14+。退出旧版或 `swift run`，解压后将 App 拖入“应用程序”。开启至少两个额度组，在“菜单栏与显示”开启自动轮播（5–60 秒）；保持弹窗关闭即可观察翻牌。
- **Windows x64 ZIP**：保留原有 Codex 托盘功能，仅同步版本为 1.4.1；不包含 macOS 翻牌、主题、多供应商及 Touch Bar。解压后运行 `CodexTokenMonitor.exe`，无需另装 .NET。
- macOS 包为 **ad-hoc 签名，未经过 Apple 公证**；Windows EXE 未签名，首次运行可能出现系统安全提示。
- 已通过本地 Swift 回归测试及 Release 编译；macOS 打包检查签名完整性和离线品牌资源，Windows 逻辑检查及打包由 GitHub Actions 完成。多屏真实点击定位仍需用户真机验证。
- GIF 使用绘制代码和虚构示例数据生成，文字放大两倍便于观察，不是真实账户录屏。

## English

### macOS changes

- Added an airport-style split-flap transition when automatic rotation advances to another quota group: approximately 0.32 seconds, with slightly staggered rows.
- Keeps the system monochrome template color and transparent background. Regular quota refreshes and manual source changes do not animate.
- Retains the widest content encountered during rotation and keeps the canvas width fixed during each flip. Clicking immediately finishes the animation before the existing popover positioning logic runs. Compact width returns after rotation is disabled and the popover is closed.
- Respects Provider Settings → Appearance → Motion Off and macOS Reduce Motion. The frame timer stops after each transition; no additional API requests are made.
- Adds a complete provider/quota accessibility label. Updates the README with a rendered preview GIF, usage instructions, and download links.
- Retains v1.4.0 multi-provider monitoring, three themes, Touch Bar animations, and floating sleep Zzz. Quota endpoints and polling intervals are unchanged.

### Installation and verification

- **macOS arm64 ZIP** requires Apple Silicon and macOS 14+. Quit the previous app or `swift run`, unzip, and move the app to Applications. Enable at least two quota groups and automatic menu-bar rotation (5–60 seconds); close the popover to see the transition.
- **Windows x64 ZIP** retains the existing Codex tray features, with its version synchronized to 1.4.1. macOS split-flap animations, themes, multi-provider monitoring, and Touch Bar are not included. Extract and run `CodexTokenMonitor.exe`; no separate .NET installation is required.
- The macOS app is **ad-hoc signed, not Apple-notarized**. The Windows executable is unsigned. OS security warnings may appear on first launch.
- Local Swift regression tests and Release compilation passed. macOS packaging checks signature integrity and bundled brand resources; Windows checks and packaging run in GitHub Actions. Real multi-display click positioning still requires user hardware verification.
- The GIF is generated by the rendering code using fictional data, with text enlarged 2× for visibility; it is not a recording of a real account.
