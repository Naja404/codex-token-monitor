# v1.4.11 · Codex 重置券 / Codex Reset Credits

## 中文

- Codex 概览增加持有重置券次数，单独显示当前适用数量，展开后用独立卡片显示逐张有效期和剩余天数、小时或分钟。仅查询信息，不兑换重置券。
- 新增可选“重置券即将到期”本地通知，默认关闭。需同时开启通知总开关及该类别；成功读取有效期后，到期前 24、12、6、3、1.5、0.5 小时分阶段提醒，每张券每阶段一次，跨重启去重；重启时只提醒当前阶段。
- 刷新时保留已有信息，相同重置券数据不重复发布。明细读取失败不会影响额度读取；旧有效期有明确标记，不会用于发送到期提醒。未提供有效期与无到期限制分别显示。
- Windows 仅同步版本号，重置券及本地提醒为 macOS 功能。

macOS 提供 Developer ID 签名、Apple 公证并附加票据的 App、拖拽安装 DMG 和 ZIP。Windows 提供 x64 ZIP（EXE 未签名）。校验文件为 SHA256SUMS.txt。

升级时先退出旧版，打开 DMG，将 App 拖入 Applications 并替换，在“关于与更新”确认 **1.4.11 (24)**。

## English

- Shows owned Codex reset credits, with currently applicable counts shown separately in the overview. Expand to see individual cards with expiration dates and remaining time. Reads information without redeeming credits.
- Adds an optional local reset-expiry alert, off by default. Enable both notifications and this category to receive reminders at 24, 12, 6, 3, 1.5 and 0.5 hours before expiry, once per credit per stage across restarts. Restarting only alerts for the current stage.
- Keeps existing values during refresh and avoids republishing identical reset snapshots. Optional detail failures do not break quota reads. Cached expiry details are labeled and never trigger expiry alerts. Missing expiry and non-expiring credits are distinguished.
- Windows receives a version bump only; reset credit monitoring and local alerts are macOS features.

macOS includes a Developer ID signed, Apple-notarized and stapled app, drag-to-Applications DMG and ZIP. Windows includes an x64 ZIP (unsigned EXE). SHA-256 checksums are in SHA256SUMS.txt.

Quit the old app, mount the DMG, drag the app into Applications and replace the previous copy. Confirm **1.4.11 (24)** in About & Updates.
