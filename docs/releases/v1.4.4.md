# v1.4.4 · 稳定刷新、DMG 安装与 Gemini 4 Argon / Stable Refresh, DMG & Gemini 4 Argon

## 中文

**未公证预发布版**：本版 macOS App 使用 ad-hoc 签名，未使用 Developer ID 签名，也未经过 Apple 公证。首次打开可能被 Gatekeeper 拦截；仅在信任本项目和下载来源时使用。需要已公证稳定版时，请继续使用 [v1.4.3](https://github.com/Naja404/codex-token-monitor/releases/tag/v1.4.3)。本版不替换 Latest 稳定版。

- **刷新不闪空值**：定时查询期间菜单栏保留最近一次成功数据，有效结果到达后再替换；刷新失败也保留菜单显示，错误和最近成功时间仍在详情展示。显示内容相同就不重绘。关闭监控或更换连接配置会清除对应缓存；缓存不用于 Codex 自动回写。
- **弹窗查询期间保留数值**：各供应商卡片和明细在后台读取时继续显示已有额度与金额，只增加读取提示。
- **拖拽安装器**：macOS 新增 DMG，挂载后把左侧 App 拖到右侧 Applications；同时保留兼容 ZIP。安装后从“应用程序”启动并推出磁盘。
- **Gemini 4 Argon 独立额度**：正确识别 `gemini-argon-wtu-weekly`，与普通 Gemini、Claude + GPT 独立展示；增加概览、固定菜单来源、轮播及 Touch Bar 支持。目前 CLI 只提供每周窗口，不推算 5 小时额度。
- **README 图片已更新**：实际 DMG 窗口截图、Argon 浅色 / 深色原生概览及刷新演示 GIF。额度预览使用虚构测试数据，不含真实账户或凭据。
- **Windows**：同步为 1.4.4，保留原有 Codex 托盘及回写；不包含 macOS 多供应商、DMG、主题或 Touch Bar 功能。EXE 未签名。

### 下载与验证

- `Codex-Token-Monitor-macOS-arm64.dmg`：Apple Silicon、macOS 14+，双击后拖拽安装。
- `Codex-Token-Monitor-macOS-arm64.zip`：同一 App 的兼容压缩包。
- `Codex-Token-Monitor-Windows-x64.zip`：Windows 10/11 x64，解压后运行，自带 .NET 运行时。
- `SHA256SUMS.txt`：以上三个安装包的 SHA-256 校验和。

本地 142 项 Swift 测试通过，包含原生 Argon 概览渲染和真实 agy 1.4.7 只读查询（3 个额度组、5 个窗口）；Release 编译、App 签名 / 资源检查、DMG 校验与实际 Finder 布局检查通过。当前 GIF 导出测试也已通过。GitHub Actions 在两平台构建成功后才上传附件并发布预发布版；真实 Warp Key、Windows 托盘交互及其他硬件场景仍见 [路线图](https://github.com/Naja404/codex-token-monitor/blob/main/ROADMAP.md)。

## English

**Unnotarized prerelease:** the macOS app is ad-hoc signed, without Developer ID signing or Apple notarization. Gatekeeper may block first launch. Use it only if you trust this project and download source. [v1.4.3](https://github.com/Naja404/codex-token-monitor/releases/tag/v1.4.3) remains the notarized stable release and retains the Latest designation.

- Keeps successful menu-bar data visible while polling and after failed reads; replaces it only with valid new data and skips identical rendered frames. Errors and last-success timestamps remain in the details. Disabling monitoring or changing connection settings clears the corresponding cache. Cached display data never enters Codex reporting.
- Preserves existing provider values in the popover during reads.
- Adds a drag-to-Applications DMG while retaining the compatible macOS ZIP.
- Separates Gemini 4 Argon (`gemini-argon-wtu-weekly`) from ordinary Gemini and Claude + GPT, with summary, menu selection, rotation and Touch Bar support. Only the reported weekly window is displayed; no five-hour quota is inferred.
- Refreshes README installer, light/dark Argon and refresh-animation previews. Quota imagery uses fictional fixtures, never private account data.
- Synchronizes Windows to 1.4.4 while retaining its Codex-only tray and reporting features. The Windows executable remains unsigned.

Downloads include the macOS arm64 DMG and ZIP (macOS 14+), the self-contained Windows x64 ZIP, and `SHA256SUMS.txt`. Local validation passed 142 Swift tests, live read-only agy 1.4.7 quota parsing, the Release build, resource and ad-hoc signature checks, DMG verification and inspection of the actual Finder installer window. The native refresh GIF export also passed. Publishing waits for successful builds on both platforms; this does not replace real-account and hardware validation listed in the roadmap.
