# v1.4.8 · 可选本地通知 / Optional Local Notifications

## 中文

**正式版：macOS App 与 DMG 使用 Developer ID 签名，通过 Apple 公证并附加票据。**

- 新增设置 → **通知**：用户独立选择**低额度、额度恢复、刷新失败、登录失效**四类提醒，可调整百分比、TeamoRouter 美元余额阈值和声音。
- **通知默认关闭。** 只有开启总开关时才请求 macOS 权限；拒绝后不会反复弹授权框，设置页提供权限状态、系统设置入口和测试通知。
- 只用已启用供应商的新完成读取判断额度，支持独立 Argon 每周池、Warp 周期百分比及 TeamoRouter 美元余额；缓存、加载和缺失数据不会作为零值触发提醒。
- 同一低额度每轮只提醒一次，去重状态跨重启保留。百分比恢复到阈值以上至少 5 个百分点，余额恢复到阈值以上至少 $0.50 或阈值的 10%（取较大值）后重新允许低额度提醒；恢复类别可单独开启。
- 临时刷新失败连续 3 次读取失败才提醒；登录或密钥异常及读取已暂停可立即提醒，每次故障只提醒一次，成功读取后重置。关闭供应商会丢弃尚未发送的排队提醒。
- 使用 macOS 本地通知，无远程推送服务器，不发送密钥或原始服务错误，不增加查询频率。点击通知回到设置；应用退出后不再监测。现有快捷键、侧栏、更新检查和 DMG 保留。Windows 仅同步版本号。

### 使用与安装

先退出旧版，再通过 DMG 将 App 拖到 Applications 并选择替换。到“关于与更新”确认 **v1.4.8 (20)**。设置 → 通知中先选择类别，再开启总开关并允许系统提示，最后发送测试通知。显示方式取决于系统通知设置、声音设置和专注模式；不会自动替用户开启通知。

macOS 14+ / Apple Silicon，提供已公证 DMG 与 ZIP。Windows x64 ZIP 自带运行时，EXE 未作 Windows 代码签名。SHA256SUMS.txt 覆盖三个安装包。

### 验证

167 项 Swift 回归通过，包括授权拒绝、授权迟到、分类独立开关、去重持久化、有效零值 / 无效值、错误防抖、发送失败重试、关闭供应商时取消排队和旧菜单缓存隔离。已在打包 App 中实际查询系统通知服务；该诊断不会请求权限或发送通知。未代替用户启用系统权限，未将模拟发送记作实际横幅验证。README 图片来自隔离测试配置，不包含真实账户信息。

App 与 DMG 的签名、公证、票据、Gatekeeper、下载摘要及资源验证均在发布前完成。证书私钥和公证凭据保留在本机钥匙串。

## English

**Stable release: the macOS app and DMG are Developer ID signed, Apple-notarized and stapled.**

- Adds a Notifications settings page with independently selectable **low quota, quota recovery, refresh failure and sign-in/key problem** categories, quota/balance thresholds and sounds.
- Notifications are **off by default**. Permission is requested only when enabled. Denied permission is not repeatedly requested; permission status, System Settings and a test-notification button are provided.
- Uses fresh completed reads from enabled providers, including the separate Argon pool, Warp cycle percentage and TeamoRouter USD balance. Cached, missing and loading data never become zero-quota alerts.
- Duplicate-alert state survives restarts. Low-quota alerts rearm after recovery with a buffer of 5 percentage points, or for balances the greater of $0.50 and 10% of the threshold. Recovery alerts can be selected independently.
- Temporary refresh errors alert after 3 distinct consecutive failures. Credential problems and stopped refreshes may alert immediately, once per incident until a successful read. Disabling a provider drops its unsent queued alerts.
- Uses local macOS notifications without a remote push service, secrets or raw service errors. Polling intervals stay unchanged; monitoring stops when the app exits. Existing shortcuts, navigation, update checks and DMG remain available. Windows receives a version bump only.

Quit the previous app before replacing it in Applications. Confirm **v1.4.8 (20)**, select categories in Settings → Notifications, enable notifications and allow the system prompt, then send a test notification. macOS notification settings and Focus control how it appears. Requires macOS 14+ / Apple Silicon. Also includes a self-contained unsigned Windows x64 ZIP and SHA-256 checksums.

All 167 Swift regression tests passed. The packaged app successfully queried the real system notification service without requesting permission or sending a notification. Mock delivery is not counted as a visible system-banner test; users enable permission themselves. README imagery uses isolated sample settings. Signing, notarization, stapling, Gatekeeper, resource and download-integrity checks precede publication; signing keys remain in the local Keychain.
