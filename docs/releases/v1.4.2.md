# v1.4.2 · 折叠概览与双语 / Expandable Overview & Languages

## 中文

### macOS 更新

- 用按服务折叠的卡片替代“简介 / 明细”模式切换。打开弹窗默认折叠，点击箭头查看进度、重置时间、来源和错误；支持全部展开 / 全部收起。
- “服务与账号”增加独立的连接设置折叠区，名称和监控开关保持可见。折叠不会清空未保存的输入，隐藏输入框不可操作。
- 在“供应商设置 → 菜单栏与显示 → 语言”切换中文简体 / English，立即生效并自动保存。覆盖弹窗、设置、菜单栏、Touch Bar 及主要状态提示。
- 自动轮播增加 10 秒、30 秒、60 秒快捷按钮，保留 5–60 秒自定义间隔；弹窗打开时仍暂停轮播。
- 退出按钮增加电源图标；折叠按钮提供无障碍标签并遵守减少动态效果设置。
- README 更新原生界面的中英文、深浅色截图及菜单栏 / 弹窗 GIF。所有预览使用虚构数据，不包含真实账户或密钥。
- 额度接口、刷新频率、回写 JSON 格式和 Touch Bar 小猫的额度联动规则不变。

### 安装与验证

- **macOS arm64 ZIP**：Apple Silicon，macOS 14+。退出旧版或 `swift run`，解压后将 `Codex Token Monitor.app` 拖入“应用程序”。
- macOS 安装包使用 **Developer ID Application 签名、Hardened Runtime 和安全时间戳**；经 Apple 公证并附加票据，解压后的 App 通过 Gatekeeper 验证（Notarized Developer ID）。首次从互联网下载的普通打开确认仍可能出现。
- **Windows x64 ZIP**：版本同步为 1.4.2，保留原有 Codex 托盘功能；不包含本次 macOS 折叠界面、语言选择、多供应商、主题或 Touch Bar。解压运行 `CodexTokenMonitor.exe`，无需另装 .NET。Windows EXE 未签名。
- Swift 回归测试、原生界面示例渲染和 Release 编译已验证；Windows 逻辑检查及打包由 GitHub Actions 执行。真实多屏定位、各供应商账号及 Windows 托盘交互仍需实机验收。
- 发布流程先创建草稿，只有签名公证后的 macOS 安装包才附到正式 Release。CI 的 ad-hoc macOS 构建仅保留为 Actions artifact，不会覆盖已公证附件。私钥与公证密码保留在本机，未上传 GitHub。

## English

### macOS changes

- Replaces the Summary / Details mode switch with per-provider expandable cards. Each popover opens collapsed. Expand a card for progress bars, reset times, sources and errors, or use Expand All / Collapse All.
- Adds collapsible connection settings in Services & Accounts while keeping provider names and monitoring switches visible. Collapsing preserves unsaved input and disables hidden fields.
- Switch between Simplified Chinese and English under Settings → Menu Bar & Display → Language. Changes apply immediately and save automatically, covering the popover, settings, menu bar, Touch Bar and primary status messages.
- Adds 10-, 30- and 60-second rotation presets while retaining the custom 5–60-second interval. Rotation still pauses while the popover is open.
- Adds a power icon to Quit. Disclosure controls include accessibility labels and respect Reduce Motion.
- Updates the README with native-view screenshots in both languages and light/dark appearances, plus a menu-bar/popover GIF. Previews use fictional data, never real account details or credentials.
- Quota endpoints, polling intervals, reporting JSON and quota-linked Touch Bar cat behavior are unchanged.

### Installation and verification

- **macOS arm64 ZIP** requires Apple Silicon and macOS 14+. Quit the previous app or `swift run`, unzip, and move `Codex Token Monitor.app` to Applications.
- The macOS package is **Developer ID Application signed with Hardened Runtime and a secure timestamp**, notarized by Apple, and stapled. The extracted app passes Gatekeeper as Notarized Developer ID. A normal first-launch internet-download confirmation may still appear.
- **Windows x64 ZIP** synchronizes the version to 1.4.2 and retains the existing Codex tray functionality. This release's macOS disclosure UI, language selector, multi-provider monitoring, themes and Touch Bar are not included. Extract and run `CodexTokenMonitor.exe`; no separate .NET installation is required. The Windows executable remains unsigned.
- Swift regression tests, native fixture rendering and Release compilation were verified; Windows checks and packaging run in GitHub Actions. Real multi-display positioning, provider-account behavior and Windows tray interactions still require hardware/user validation.
- Releases are prepared as drafts. Only the locally signed and notarized macOS package is attached for publication. The ad-hoc macOS CI build remains an Actions artifact and cannot overwrite the notarized asset. Private signing keys and notarization credentials remain local and are not uploaded to GitHub.
