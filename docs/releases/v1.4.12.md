# v1.4.12 · 统一重置券数量 / Consistent Reset Credit Counts

## 中文

- 修正展开明细仍显示“当前适用 0 张”的误导：概览和明细现在统一使用持有数量，持有两张券时两处都显示两张。
- 不再将其他内部计数用于判断券是否可用。实际兑换条件请在 Codex 中确认；Monitor 仅查看信息。
- 保留独立重置券卡片、有效期、倒计时，以及可选的 24、12、6、3、1.5、0.5 小时递进提醒。

macOS App 与拖拽安装 DMG 均使用 Developer ID 签名、通过 Apple 公证并附加票据。Windows 仅同步版本号，提供未签名的 x64 ZIP。校验文件为 SHA256SUMS.txt。

升级时先退出旧版，将 DMG 内的 App 拖入 Applications 并替换，确认版本为 **1.4.12 (25)**。

## English

- Fixes the misleading “0 currently applicable” count in expanded details. Both the overview and details now show the owned credit count consistently.
- Removes the internal applicability counter from the display. Confirm redemption conditions in Codex; Monitor only reads information.
- Preserves individual credit cards, expiry dates, countdowns and optional reminders at 24, 12, 6, 3, 1.5 and 0.5 hours before expiry.

The macOS app and drag-to-Applications DMG are Developer ID signed, Apple-notarized and stapled. Windows receives a version bump only and includes an unsigned x64 ZIP. SHA-256 checksums are in SHA256SUMS.txt.

Quit the old app, drag the app from the DMG into Applications and replace it. Confirm **1.4.12 (25)**.
