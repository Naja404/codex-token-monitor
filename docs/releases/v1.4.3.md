# v1.4.3 · 液态玻璃与顺滑折叠 / Liquid Glass & Smoother Disclosures

## 中文

### macOS 更新

- 新增第四套主题“液态 · 玻璃”：半透明系统材质、更加清晰的边缘反光与层次。提供浅色、深色、跟随系统和两列主题预览，选择即时生效并保存；默认主题仍为“原生 · 清透”，不覆盖已有偏好。
- 使用 macOS 14 可用的 SwiftUI Material、渐变和阴影实现玻璃风格，最低系统要求不变。**不是 macOS 26 原生 Liquid Glass API**，不宣称真实折射或形态融合效果。
- 折叠内容使用约 260ms 展开 / 180ms 收起过渡，高度、透明度与箭头同步；快速连续点击可以反向中断，不排队播放。设置中的未保存输入继续保留，折叠内容不可操作。
- 修复刷新成功高光与“全部展开 / 全部收起”同时发生时的卡片重叠、位置错乱和边框残影。刷新高光只改变颜色透明度，再按当前卡片轮廓裁切，不再让整张卡片加入刷新动画。
- 遵守系统“减少动态效果”“减少透明度”和“增强对比度”。不开启持续粒子或后台装饰动画，菜单栏仍保持系统单色。
- 更新 README 中的玻璃主题、外观设置及示例预览，新增 ROADMAP 区分已实现、待真实账号 / 硬件验证、下一阶段和暂缓范围。截图与 GIF 使用虚构数据，不含真实账户或凭据。
- 保留 v1.4.2 的双语、单卡 / 全部折叠、可折叠连接设置及轮播快捷项。额度接口、刷新频率、回写 JSON、凭据存储方式和 Touch Bar 小猫联动规则不变。

- **macOS arm64 ZIP**：Apple Silicon，macOS 14+。先退出旧版或 `swift run`，解压后将 `Codex Token Monitor.app` 拖入“应用程序”。在“供应商设置 → 外观”选择“液态 · 玻璃”。
- **本版 macOS 安装包已验证**：使用 Developer ID Application、Hardened Runtime 与安全时间戳签名，Apple 公证结果为 Accepted，已附加公证票据。最终 ZIP 解压后的 App 通过 `codesign --deep --strict`、`stapler validate`、Gatekeeper（Notarized Developer ID）与 `--verify-resources` 检查，版本号为 1.4.3。
- **Windows x64 ZIP**：版本同步为 1.4.3，保留原有 Codex 托盘及回写功能。不包含 macOS 多供应商、玻璃主题、折叠动效或 Touch Bar；解压运行 `CodexTokenMonitor.exe`，无需另装 .NET，EXE 仍未签名。
- 本地 134 项 Swift 测试、3 项额外原生折叠渲染测试与 arm64 Release 编译通过；原生示例截图和 6 帧演示 GIF 已更新并复核。离线测试不代表各套餐、真实 Warp Key、Windows 托盘或全部多屏场景已实机验收，详见 ROADMAP。
- Windows 包由 GitHub Actions 构建并附入草稿 Release；两平台 CI 与附件核对通过后才发布。实际发布状态及安装包以 [v1.4.3 Release](https://github.com/Naja404/codex-token-monitor/releases/tag/v1.4.3) 为准。
- 正式 macOS 附件由本机签名公证后上传；CI 的 ad-hoc macOS 包仅作为 Actions artifact 保留。私钥、公证密码及用户录屏不上传仓库或 Release。正常的首次互联网下载确认仍可能出现。

## English

### macOS changes

- Adds a fourth theme, **Liquid · Glass**, with translucent system materials, clearer reflective edges and stronger visual layering. Includes light, dark and system appearances plus a two-column theme selector. Changes save immediately; Native · Clear remains the default and existing preferences are preserved.
- Uses SwiftUI Material, gradients and shadows available on macOS 14, without raising the minimum OS version. **This is not the native macOS 26 Liquid Glass API** and does not claim true refraction or shape-merging effects.
- Adds approximately 260ms expand / 180ms collapse transitions, coordinating content height, opacity and chevrons. Rapid clicks reverse an in-flight transition instead of queuing animations. Unsaved settings input is preserved and collapsed controls remain non-interactive.
- Fixes overlapping, misplaced cards and stray outlines when refresh-success highlights coincide with Expand All / Collapse All. The highlight animates color opacity and is masked to the current card outline; the refresh animation no longer wraps the entire card.
- Respects Reduce Motion, Reduce Transparency and Increase Contrast. No continuous particles or background decorative animation are added; the menu bar retains its system monochrome appearance.
- Updates README glass-theme and appearance-settings previews and adds a ROADMAP separating implemented work, real-account/hardware validation, next steps and deferred scope. Screenshots and GIFs use fictional data, never real account details or credentials.
- Retains v1.4.2 language switching, individual/batch disclosures, collapsible connection settings and rotation presets. Quota endpoints, polling intervals, reporting JSON, credential storage and quota-linked Touch Bar cat behavior are unchanged.

### Installation and verification

- **macOS arm64 ZIP** requires Apple Silicon and macOS 14+. Quit the previous app or `swift run`, unzip, and move `Codex Token Monitor.app` to Applications. Select Liquid · Glass under Provider Settings → Appearance.
- **This version's macOS package is verified**: signed with Developer ID Application, Hardened Runtime and a secure timestamp; Apple notarization returned Accepted and the ticket is stapled. The app extracted from the final ZIP passed `codesign --deep --strict`, `stapler validate`, Gatekeeper (Notarized Developer ID) and `--verify-resources` checks, with its version confirmed as 1.4.3.
- **Windows x64 ZIP** synchronizes the version to 1.4.3 and retains existing Codex tray and reporting features. It does not include macOS multi-provider monitoring, glass themes, disclosure animations or Touch Bar. Extract and run `CodexTokenMonitor.exe`; no separate .NET installation is required. The executable remains unsigned.
- All 134 local Swift tests, 3 additional native disclosure-rendering tests and the arm64 Release build passed. Native fixture screenshots and the six-frame walkthrough GIF were refreshed and reviewed. Offline tests do not establish real-account, personal Warp Key, Windows tray or every multi-display scenario as validated; see the ROADMAP.
- GitHub Actions builds the Windows package and attaches it to a draft Release; publication follows successful CI for both platforms and asset checks. The [v1.4.3 Release](https://github.com/Naja404/codex-token-monitor/releases/tag/v1.4.3) is authoritative for publication status and downloads.
- The official macOS asset is signed and notarized locally before upload. The ad-hoc macOS CI build remains an Actions artifact. Private signing keys, notarization credentials and the user's screen recording are not uploaded to the repository or Release. A normal first-launch internet-download confirmation may still appear.
