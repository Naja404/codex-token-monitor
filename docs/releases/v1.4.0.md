# v1.4.0 · 多供应商与外观主题 / Multi-provider monitoring & themes

## 中文

### macOS 新增

- 多供应商监控：Codex、Antigravity CLI、Claude Code 官方 OAuth、Warp 个人 Credits、TeamoRouter API 余额与用量。每项独立开关、验证和刷新状态。
- 兼容 Claude Code 通过 TeamoRouter 环境变量 API Key 使用的情况：从 `~/.zshrc` 安全导入字面量配置，或手动填写；保存至本机钥匙串。不会执行 Shell 配置，也不会改写 Claude 登录状态。
- TeamoRouter 展示账户 USD 余额、当前 Key 的今日消费、已用 Token 和请求数。不伪造剩余百分比、不把第三方密钥发送到 Anthropic。已完成本机真实只读接口验证。
- 默认简介 / 可切换明细；菜单栏可按 5–60 秒间隔轮播已启用的数据源。
- 原生清透、极光微光、深空石墨三套主题；浅色 / 深色 / 跟随系统，支持关闭动效和系统无障碍偏好。
- 恢复原生 Touch Bar 与动态小猫，数据源跟随菜单栏；余量低于 10%、没有有效数据或只有金额没有百分比时，小猫熟睡。
- 熟睡时保留轻微呼吸，Zzz 错峰向上漂浮、逐渐淡出；遵循系统“减少动态效果”。
- README 更新多供应商演示 GIF、设置截图、各档 Touch Bar 动画和接入条件。

### 下载与注意事项

- **macOS arm64 ZIP**：Apple Silicon，macOS 14 或更新版本。解压后将 App 拖入“应用程序”；先退出旧版或 `swift run` 进程。
- **Windows x64 ZIP**：保持原有 Codex 托盘功能，本次仅同步版本号；不包含 macOS 多供应商、主题或 Touch Bar。
- macOS 包使用 **ad-hoc 签名，未经过 Apple 公证**；Windows EXE 未进行代码签名。首次运行可能被系统安全策略拦截。
- 新供应商默认关闭。请在“供应商设置 → 服务与账号”中配置、验证后开启。TeamoRouter：导入 → 保存 → 验证连接 → 开启；每 5 分钟刷新。
- Warp 和 Claude OAuth 的额度接口不保证长期稳定；Warp 尚未使用真实个人 Key 完成端到端验证。失败和未知值显示占位符，不当作零额度。
- 所有截图和 GIF 使用测试数据，不含个人密钥或真实账户信息。Windows 构建与检查由 GitHub Actions 完成。

## English

### New on macOS

- Independent monitoring for Codex, Antigravity CLI, Claude Code subscription OAuth, Warp personal Credits, and TeamoRouter API billing.
- Support for Claude Code configured with TeamoRouter via `ANTHROPIC_BASE_URL` and `ANTHROPIC_AUTH_TOKEN`: import literal assignments from `~/.zshrc` without executing it, or enter credentials manually. Saved credentials stay in the local macOS Keychain.
- TeamoRouter shows account-wide USD balance and the current key's daily cost, used tokens, and requests. Daily ranges use the Mac's local timezone. No fabricated remaining percentage; third-party credentials are never sent to Anthropic. Live read-only verification completed locally.
- Compact summary and detailed views, plus menu-bar source rotation every 5–60 seconds.
- Three themes: Native, Aurora, and Graphite; light/dark/system appearance and accessibility-aware motion controls.
- Native Touch Bar follows the selected menu-bar provider. The animated cat sleeps below 10%, without valid quota data, or when only a monetary balance is available.
- Sleeping includes gentle breathing and staggered Zzz symbols drifting upward and fading out, respecting Reduce Motion.
- Refreshed README screenshots, multi-provider walkthrough GIF, and Touch Bar animation gallery.

### Downloads and limitations

- **macOS arm64 ZIP** requires Apple Silicon and macOS 14+. Quit the previous app / `swift run`, unzip, then move the app to Applications.
- **Windows x64 ZIP** retains the existing Codex tray features; only its version is synchronized. The new macOS providers, themes, and Touch Bar are not included.
- The macOS app is **ad-hoc signed, not Apple-notarized**. The Windows executable is unsigned. OS security warnings may appear.
- New providers are opt-in. Configure and verify in Provider Settings before enabling polling. TeamoRouter refreshes every five minutes.
- Warp and Claude OAuth usage endpoints may change; Warp has not yet been verified end-to-end with a real personal API key. Missing or failed data is shown as unavailable, never as a fabricated zero.
- Screenshots and GIFs use fixtures, not private account data. Windows builds and checks run in GitHub Actions.
