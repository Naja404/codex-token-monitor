# v1.4.7 · 设置侧栏、关于与更新 / Settings Navigation & Update Checks

## 中文

**正式版：macOS App 与 DMG 均已 Developer ID 签名、通过 Apple 公证并附加票据。**

- 修复设置侧栏空白区域点击：五个导航项通过整行原生按钮接收点击，选中与未选中状态一致。宿主命中测试覆盖右侧空白及行内边距。
- 新增“关于与更新”：显示完整 GitHub 项目地址、当前版本和构建号，提供“检查更新”和发布页入口；侧栏底部也显示 GitHub 链接及版本。
- 默认检查正式版，可选择包含预发布。使用语义版本比较，跳过草稿、无 macOS 安装包和无效版本；新版本、已是最新、网络失败和 GitHub 限流分别显示。仅手动检查，不自动下载或安装，不发送供应商凭据。
- 保留 Cmd+V / Cmd+W 等标准快捷键、稳定刷新、独立 Gemini 4 Argon 额度和拖拽安装器。Windows 功能保持原样，仅同步版本号。

### 安装

macOS 14+ / Apple Silicon：**先退出旧版**，挂载 DMG，将 App 拖入 Applications 覆盖安装，再从“应用程序”打开。到“关于与更新”确认 **v1.4.7 (19)**。也提供兼容 ZIP。Windows x64 ZIP 自带 .NET 运行时；EXE 未做 Windows 代码签名。

### 验证

完整 Swift 回归、原生宿主中的中英文导航命中/页面切换、更新检查版本/错误处理及真实 GitHub 请求均通过。窗口自动化工具未能读取原生窗口，因此未记作手工鼠标实测。README 的新增图片来自最终源码的无账户原生视图预览，开发环境显示“开发版本”；安装包读取自身版本号。

App 公证：`91588ae9-17ea-4d13-982a-95d4e867fde3`，DMG 公证：`2d9f701e-3661-42ed-ae96-e62fd4e6c90e`，均为 **Accepted**。App/DMG 票据、codesign、Gatekeeper（Notarized Developer ID）、镜像内 App 与资源验证通过。私钥和公证凭据保留在本机钥匙串。两平台 CI 成功后发布，SHA256SUMS.txt 提供三个安装包校验和。

## English

**Stable release: both the macOS app and DMG are Developer ID signed, Apple-notarized and stapled.**

- Settings sidebar rows now route their full bounds through native controls, including right-hand blank space and padding. Selected and unselected rows behave consistently.
- Adds About & Updates with the full GitHub repository URL, installed version/build, Check for Updates and release-page links. The sidebar also displays GitHub and version information.

Network/rate-limit failures never claim the app is up to date. Checks are manual; downloads and installation remain user initiated. No provider credentials are sent.
- Retains macOS keyboard shortcuts, stable quota refresh, the independent Gemini 4 Argon pool and the DMG installer. Windows receives a version bump only.

Quit the previous app before replacing it in Applications, then confirm **v1.4.7 (19)** in About & Updates. Requires macOS 14+ on Apple Silicon. Also includes a self-contained, unsigned Windows x64 ZIP and SHA-256 checksums.

Swift regression tests, bilingual native-host hit tests, navigation state changes, update-selection/error tests and a live GitHub request passed. Native-window automation timed out; this is not recorded as manual mouse validation. README imagery is a native preview without account data. The app and DMG both received **Accepted** notarization results; stapler, codesign, Gatekeeper and mounted-app resource checks passed before publication. Signing keys and notarization credentials remain in the local Keychain.
