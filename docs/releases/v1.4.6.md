# v1.4.6 · 设置侧栏整行可点击 / Clickable Settings Sidebar Rows

## 中文

**未公证预发布版**：macOS App 使用 ad-hoc 签名，未经 Apple 公证，首次打开可能被 Gatekeeper 拦截。[v1.4.3](https://github.com/Naja404/codex-token-monitor/releases/tag/v1.4.3) 继续作为已公证的 Latest 稳定版。

- 修复设置侧栏只能点击图标或文字的问题。服务与账号、菜单栏与显示、外观、Codex 回写现在都支持点击整行空白处切换。
- 点击区域覆盖完整行宽与行内边距，选中、未选中状态一致；布局和选中背景保持原样。
- 保留 v1.4.5 的 Cmd+V、Cmd+W 等标准 macOS 快捷键，以及稳定刷新、Gemini 4 Argon 独立额度和 DMG 安装器。Windows 仅同步版本号。

macOS 14+ / Apple Silicon：先退出旧版，下载 DMG 并将应用拖入 Applications 覆盖安装；也提供 ZIP。Windows x64 ZIP 自带运行时。SHA256SUMS.txt 提供三个安装包的校验和。

现有 145 项 Swift 测试通过；本次修复未新增测试，也未记作手工鼠标实测。两平台安装包由 GitHub Actions 构建后发布。

## English

**Unnotarized prerelease:** the macOS app is ad-hoc signed and has not been notarized by Apple. Gatekeeper may block first launch. [v1.4.3](https://github.com/Naja404/codex-token-monitor/releases/tag/v1.4.3) remains the notarized Latest stable release.

- Fixes settings sidebar rows responding only to clicks directly on their icon or text. All four navigation rows now accept clicks across their full width, including empty space and padding.
- Selected and unselected rows share the same hit area. Layout and selection appearance are unchanged.
- Retains standard macOS keyboard shortcuts, stable refresh behavior, the independent Gemini 4 Argon pool and the DMG installer. Windows receives a version bump only.

Quit the previous macOS app before installing from the DMG or ZIP. Includes a self-contained Windows x64 ZIP and SHA-256 checksums for all three packages.

All 145 existing Swift tests passed. This one-line hit-area fix adds no new test and is not recorded as manual mouse validation. Packages are built by GitHub Actions before publication.
