# v1.4.5 · 修复 macOS 标准快捷键 / Restore macOS Keyboard Shortcuts

## 中文

**未公证预发布版**：macOS App 使用 ad-hoc 签名，未使用 Developer ID，也未经过 Apple 公证。首次打开可能被 Gatekeeper 拦截。需要已公证稳定版时，请继续使用 [v1.4.3](https://github.com/Naja404/codex-token-monitor/releases/tag/v1.4.3)；本版不替换 Latest 稳定版。

- 修复供应商配置页不能使用 **Cmd+V 粘贴**的问题，并恢复 **Cmd+C 拷贝、Cmd+X 剪切、Cmd+A 全选、Cmd+Z 撤销、Cmd+Shift+Z 重做**。
- 修复 **Cmd+W 不能关闭设置窗口**的问题。只关闭当前窗口，菜单栏监控继续运行；可以再次打开设置。
- 补齐标准 AppKit 应用、文件、编辑和窗口菜单，支持 **Cmd+M 最小化、Cmd+Q 退出**，菜单名称随应用的中英文设置更新。
- 不需要额外开启系统快捷键或申请键盘监控权限。编辑操作沿原生第一响应者链交给当前输入框，密钥输入框保留原生的禁止复制 / 剪切保护。
- 保留 v1.4.4 的稳定刷新、Gemini 4 Argon 独立额度、DMG 安装器与 README 图片。Windows 功能不变，仅同步版本号为 1.4.5。

根因是应用改为 AppKit 常驻菜单栏生命周期后，没有安装标准 mainMenu；窗口中虽然有可编辑字段和关闭按钮，但相应 Command 菜单快捷键没有注册。

### 下载与验证

macOS 14+ / Apple Silicon：下载 `Codex-Token-Monitor-macOS-arm64.dmg`，先退出旧版，再挂载并拖到 Applications；也提供兼容 ZIP。Windows 10/11 x64：解压 Windows ZIP 运行，自带 .NET 运行时，EXE 仍未签名。`SHA256SUMS.txt` 包含三个安装包的校验和。

145 项本地 Swift 测试通过，包括普通及安全输入框的菜单按键匹配、真实编辑器粘贴 / 全选 / 复制保护、实际设置窗口关闭和重开，以及菜单中英文与快捷键一致性。SwiftPM 测试宿主没有前台应用的 key window，因此动作测试显式指定真实编辑器 / 窗口作为测试目标；生产菜单仍使用 nil target，由 AppKit 分发。实际窗口检查工具本次启动超时，未记作手工键盘实测。发布流程等待两平台构建通过后才上传附件并发布。

## English

**Unnotarized prerelease:** the macOS app is ad-hoc signed, without Developer ID signing or Apple notarization. Gatekeeper may block first launch. [v1.4.3](https://github.com/Naja404/codex-token-monitor/releases/tag/v1.4.3) remains the notarized Latest stable release.

- Restores **Cmd+V paste**, **Cmd+C copy**, **Cmd+X cut**, **Cmd+A select all**, **Cmd+Z undo** and **Cmd+Shift+Z redo** in provider settings.
- Restores **Cmd+W** to close the current settings window while menu-bar monitoring continues. Settings can be reopened.
- Adds standard AppKit application, File, Edit and Window menus, including **Cmd+M** and **Cmd+Q**, with Chinese/English labels.
- No system shortcut switch or keyboard-monitoring permission is needed. Editing follows the native responder chain; secure fields retain their native copy/cut protection.
- Keeps v1.4.4's refresh behavior, independent Argon pool, DMG installer and README imagery. Windows functionality is unchanged; its version is synchronized to 1.4.5.

The AppKit lifecycle did not install a main menu, so standard menu key equivalents were missing even though fields and window buttons worked. All 145 local Swift tests passed. Tests exercise key-equivalent matching, native field-editor actions, secure copy protection, settings-window closing/reopening and localized menu bindings. Because the SwiftPM host has no foreground key window, action tests explicitly route to real editors/windows; production items retain nil targets for AppKit routing. The live-window inspection tool timed out and is not counted as manual keyboard validation. Publishing waits for both platform builds and includes macOS DMG/ZIP, Windows x64 ZIP and SHA-256 checksums.
